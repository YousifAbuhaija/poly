## How Matching Works

When you take the quiz:
- Each "For" answer = +1
- Each "Against" answer = -1
- Each "No Opinion" = 0

The system compares YOUR answers to each politician's positions:
- If you both agree (both 1 or both -1) = MATCH
- If you disagree (you say 1, they say -1) = NO MATCH
- If either is neutral (0) = SKIP

Match % = (Matches / Total Answered) × 100
